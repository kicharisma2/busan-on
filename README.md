# 🌊 부산ON 월드 (BUSAN ON WORLD)
> **"시청에 들어가는 순간, 부산의 모든 시민과 소통이 연결됩니다."**  
> **부산광역시청을 실제 공간 그대로 재현한 3D 시민소통 판타지 메타버스 & AI 행정 안내 플랫폼**

---

## 🌟 프로젝트 소개 (Overview)

**부산ON 월드**는 기존의 딱딱한 관공서 홈페이지를 탈피하여, **부산광역시청(연제구 중앙대로 1001)**의 실제 건축과 광장을 3D 가상세계로 완벽하게 재현하고, 시민들이 공무원에게 직접 전화하거나 민원을 넣기 전 **부담 없이 익명으로 질문하고, 서로 정보를 나누며, 생활 속 불만과 아이디어를 자유롭게 외칠 수 있는 열린 시민 소통 공간**입니다.

기존에 개발된 두 가지 전문 행정 서비스:
1. **정부청사 사무실 안내 시스템** (`https://sejong-office-app.web.app/`)
2. **공공기관 소관부서 및 사무분장 법령 검증 엔진** (`https://kicharisma2.github.io/division-in-charge/`)
의 핵심 엔진과 데이터를 부산광역시 및 16개 자치 구·군에 맞게 완벽히 흡수·통합하였습니다.

---

## 🏛️ 주요 구현 공간 (3D World Architecture)

### 1. 야외 5대 테마 시청광장 (약 39,797㎡ 실제 부지 기반)
- **시민광장**: 해양수도 부산을 상징하는 거대한 은빛 **'부산의 닻(Anchor)'** 조형물, 춤추는 바닥 분수대, 실시간 시민 담벼락 전광판.
- **등대광장**: 오륙도 등대를 모티브로 한 회전 탐조등 조형물과 푸른 소원 연못(Wish Pond).
- **동백광장**: 부산시화인 붉은 동백꽃 가로수길과 산책로 벤치, 떨어지는 꽃잎 효과.
- **녹음광장**: 울창한 조경수목으로 둘러싸인 반원형 계단식 야외 버스킹 공연장.
- **잔디광장 & 속 시원한 시민 발언대**: 천연 잔디밭과 대형 황동 확성기가 설치된 발언대 단상 (외치기 시 서버 전체 방송).

### 2. 부산광역시청 본관 (지하 3층 ~ 지상 28층 타워)
- **1층 열린로비 '들락날락'**: 어린이·시민 복합문화공간, 곡선형 우드 서가, 미디어아트 월, AI 안내데스크('다온' 상주).
- **1층 부산미래도시관**: 16개 자치 구·군 3D 축소 디오라마 테이블 (원하는 지역 클릭 시 즉시 텔레포트).
- **2층 행복민원실 (통합민원과)**: 여권신청 창구, 원스톱 복합민원 창구, 120 바로콜센터 현장상담 부스, 아주라(아이돌봄) 수유실, 대기 번호표 키오스크.

## 💡 핵심 서비스 기능

| 메뉴 | 주요 기능 설명 |
|---|---|
| **🤖 AI 행정안내소 (다온 & 부기)** | 공무원에게 전화하기 전, 무엇이든 가볍게 질의. 소관부서(시청 본청 vs 관할 구청) 자동 판별, 직통 전화번호, 법령 근거 및 공식 민원사이트(120, 안전신문고, 정부24) 직통 연계 |

| **🗣️ 시민 자유담벼락 & 불만 분출 광장** | 익명으로 불만 외치기, 정책 제안, 칭찬, 질문을 남길 수 있는 열린 커뮤니티 (공감, 댓글, 필터 지원) |
| **🌐 16개 구·군 디오라마 포털** | 연제, 해운대, 부산진, 동래, 남구, 중구, 서구, 동구, 영도, 북구, 사하, 금정, 강서, 수영, 사상, 기장군 청사 연계 |
| **📸 실제 청사 사진 & 구조 투어** | 실제 부산시청 항공 전경, 닻 조형물, 들락날락, 행복민원실 실물 사진 갤러리 및 건축 구조 안내 |
| **📖 시민 탐험가 스토리 퀘스트** | ACT 1~5 스토리라인 및 스탬프 투어, 9단계 시민 계급 성장(경험치 및 칭호 시스템) |

## 🚀 빠른 실행 방법 (How to Run)

### 1. 로컬 환경에서 실행 (권장)
바탕화면의 `부산ON_실행하기.bat` 파일을 더블클릭합니다.
```bash
python server.py
# 웹 브라우저가 자동으로 열리며 http://localhost:8080/index.html 로 접속됩니다.
```

### 2. 전 세계 인터넷 공유 서버로 실행 (Cloudflare Tunnel)
`부산ON_글로벌_인터넷서버_시작.bat` 파일을 더블클릭합니다.
- 공인 인터넷 접속 링크(https://xxx.trycloudflare.com/index.html)가 자동 생성되어 친구나 시민들과 링크 하나로 바로 멀티 접속이 가능합니다.

## 🛠️ 기술 스택 (Tech Stack)
- **Frontend**: Three.js, OrbitControls, Web Audio API Synthesizer (`audio.js`), Vanilla JS, Modern Responsive CSS3 (Glassmorphism)
- **Backend**: Python 3 (ThreadingHTTPServer, RFC 6455 WebSocket Handshake/Stream Server, REST API)
- **Data Architecture**: Busan City Hall Office Floors (1F~28F), Master Division Jurisdiction Knowledge Base, 16 Districts Metadata, Citizen Wall JSON Persistence
